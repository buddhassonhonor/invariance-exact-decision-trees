# Invariance-Regularized Exact Decision Trees

Code and data supporting **Invariance-Regularized Exact Decision Trees under Cross-Environment Distribution Shift** by Zhigao Huang, Pinghui Wu, Miao Pan, Rongwen Hong, Quanfa Li, and Yueqian Ke. Release **2.0.0** implements the current source-only evaluation; previous repository history describes an earlier protocol.

CIEDT globally optimizes a depth-bounded tree under an additive error and source-leaf stability objective. Exact optimization concerns that objective, not a guarantee of target generalization.

## Contents

The archive contains experiment code, pinned requirements, 24 primary jobs, 216 prediction sets, serialized trees (including cold and warm RobustOCT fits), selection and sample manifests, supplementary result tables, and PNG figures. No manuscript, submission correspondence, credentials, proprietary license, or build log is included.

The primary benchmark compares nine methods across five seeds for Synthetic XOR, scikit-learn Digits 0/1, Breast Cancer, and Wine class 0/rest, and four held-out UCI Heart Disease hospitals. Controlled macro target accuracy is 0.856 for CIEDT and 0.816 for pooled-error exact trees. Heart macro balanced accuracy is 0.675 and 0.719, respectively. Era variants are single-tree adaptations; MurTree, Strong OCT, and SPLIT are not reproduced numerical baselines. RobustOCT uses the official ODTLearn implementation and reports time-limited incumbents with their gaps.

## Setup and checks

Use Python 3.11 and install dependencies into an isolated environment:

```sh
python -m venv .venv
python -m pip install -r experiment/requirements-eswa.txt
python experiment/src/verify_eswa_models.py
python experiment/src/pr_validate_results.py
```

Activate the environment before running the commands (Windows: `.venv/Scripts/Activate.ps1`; Linux/macOS: `source .venv/bin/activate`). Saved-result validation checks predictions, trees, source-only selection and disjoint fold IDs without fitting RobustOCT. A valid Gurobi license is needed for new RobustOCT fits.

## Reproduction

From the repository root:

```sh
python experiment/src/eswa_suite.py --panel all --workers 2
python experiment/src/eswa_warm_robust.py --workers 4
python experiment/src/eswa_supplement.py --part all
python experiment/src/eswa_sensitivity.py
python experiment/src/eswa_shift.py
python experiment/src/eswa_report.py
python experiment/src/pr_validate_results.py
```

Existing jobs are reused. For fresh fits, use a separate copy and move the saved jobs, prediction/model directories, and any generated solver caches aside before execution. Reusing results does not constitute a new runtime measurement. The report script generates experimental tables and figures, not the article text. The serialized primary jobs preserve the source-only preprocessing, sample IDs and selected configurations used in the reported evaluation.
